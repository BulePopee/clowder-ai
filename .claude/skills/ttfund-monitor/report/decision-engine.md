# Module: Decision Engine
# Role: Evidence-Driven Market Wind Diagnosis

## Purpose

基于 snapshot 数据判断市场风向和操作倾向。规则用于保证客观和可追溯，不用于穷举分类。

## Core Principle

```
数据 → 市场风向 → 风险含义 → 操作倾向
```

不是：

```
指标 → 条件计数 → regime 标签 → 查表动作
```

金融市场是混沌系统。规则管证据链和纪律，不管"市场该怎么走"。

### Step 2: Dominant Driver Judgment

从资产联动反推主导驱动力。不枚举全部可能性，只判断本轮最可能的 1 个主导 + 被排除的选项。

**可测量驱动力**（每个判断必须有 snapshot 数据支撑）:

| 驱动力 | 核心证据 | 支持判断 | 排除判断 |
|--------|---------|---------|---------|
| 实际利率 | B8 TIPS, B1 30Y, G2 金, E1 NDX | TIPS↑ + 金↓ + NDX↓ = 实际利率冲击 | 金↑ + TIPS↓ = 不是 |
| 通胀预期 | B9 breakeven, O1 油价, F2 PCE | breakeven↑ + 金↑ + 油↑ = 通胀冲击 | 金↓ + 油↓ = 不是 |
| 政策利率 | B4 FedWatch, B3 2Y, N4 IORB | 加息概率↑ + 2Y↑ = 鹰派重定价 | 降息概率↑ = 不是 |
| 信用风险 | B10 HY OAS, A2 信用利差, TED N7 | OAS↑ + TED↑ + VIX↑ = 信用压力 | OAS↓ + VIX↓ = 不是 |
| 流动性 | N6 FRA-OIS, S1 VIX, N2−N4, A1 MOVE | FRA-OIS↑ + VIX↑ = 流动性紧张 | FRA-OIS↓ + VIX↓ = 不是 |
| 美元外部压力 | X1 DXY, X5 CNH−CNY, N5 MMF AUM | DXY↑ + CNH−CNY 扩大 + MMF↑ = 美元荒 | DXY↓ + CNH−CNY 收窄 = 不是 |

**名义利率拆分**（B8 TIPS + B9 breakeven 可用时）:

| 组合 | 含义 |
|------|------|
| 名义10Y↑ + TIPS↑ + 金↓ + NDX↓ | 实际利率冲击 |
| 名义10Y↑ + breakeven↑ + 金↑ + 油↑ | 通胀预期冲击 |
| 名义10Y↓ + TIPS↓ + 金↑ + VIX↑ | 信用/避险需求 |

### Step 3: Uncertainty Declaration

明确写本轮判断的不确定性：

- **数据矛盾**: 列出方向冲突的指标对（如 DXY↑ 但 CNH 强于 CNY）
- **无法判断的方向**: 明确说"目前数据不支持明确判断"
- **等待中的关键事件**: 如 7/28-29 FOMC

**允许说"不确定"。** "数据不足以判断方向"是有效结论，比强行贴标签更有价值。

## Regime Tags (Optional, Secondary)

Regime 标签仅作为辅助参考，不出现在报告摘要首句。

| 标签 | 含义 | 何时出现 |
|------|------|---------|
| 利率驱动 | 实际利率/通胀预期/政策利率是主导 | FedWatch 有方向性概率 + 30Y/2Y 有趋势 |
| 地缘驱动 | 地缘冲突→油价→通胀是主导 | 油价供给冲击 + 地缘事件升级 |
| 信用/流动性驱动 | VIX/信用利差/资金流是主导 | VIX>25 或 OAS 大幅走阔 |
| 无强主导方向 | 多个驱动力拉锯，方向不明 | 资产方向矛盾 + 关键事件前等待 |

> Regime 标签在报告中作为第 2 章末尾一句话标注，格式：`辅助标签：{利率驱动/地缘驱动/信用驱动/无强主导方向}`。不做 A/B/C 选择题。

## Condition → Action Traceability

第 6 章每个操作建议必须引用数据证据。格式：`{数据变化} → {风险含义} → {建议动作}`。

### 通用触发条件

| 数据变化 | 风险含义 | 操作倾向 | 等级 |
|---------|---------|---------|:--:|
| B8 TIPS↑ + E1 NDX 跌破 20MA | 实际利率冲击风险资产 | 讨论减持高久期 QDII | 讨论级 |
| B4 加息概率 >60% + B1 30Y↑ | 鹰派确认，利率上行 | 维持防御，延缓切换 | 讨论级 |
| B4 降息概率 >50% + B1 30Y↓ + B9 稳定 | 鸽派转向信号 | 讨论恢复正常配置 | 讨论级 |
| B10 HY OAS >500bp 或 N7 TED >100bp | 信用市场压力 | 启动防御审查 | 建议级 |
| G2 单日 −3%+ 且 G11 <−3% | 黄金恐慌抛售 | 讨论黄金止损 | 讨论级 |
| 配置偏移 > 阈值(股±5% 或单类±3%) | 组合偏离目标 | 再平衡操作 | 执行级 |
| N6 FRA-OIS >20bp + S1 VIX >25 | 美元流动性紧张 | 讨论增加现金缓冲 | 讨论级 |

### 动作等级

| 等级 | 含义 | 前提 |
|:--:|------|------|
| 执行级 | 给出具体操作指令 | 数据置信度 ≥ 中高 + 关键指标全齐 |
| 建议级 | 给出方向建议 + 风险提示 | 数据置信度 ≥ 中 |
| 讨论级 | 提出议题，标注"等待下一轮确认" | 无限制 |

## Gold Conditions

### 持仓预警

| 级别 | 条件 | 动作 |
|:--:|------|------|
| 🟢 | SPDR 持仓稳定 + G11 溢价 −3%~+5% | 维持 |
| 🟡 | SPDR 连续流出 或 G11 折价扩大 | 下轮加密 |
| 🔴 | SPDR 连续流出 + G11 <−3% 或 >+5% | 触发减仓讨论 |

### 卖出条件（须同时满足 3 条）

1. 美联储明确降息路径（锚崩溃叙事结束）
2. 油价持续 <$80 + 通胀压力消除
3. DXY 明显走强 + 黄金跌破关键支撑（COMEX <$4,100）

## Round Strategy

| 场景 | 触发 | 采集 | 深度 |
|------|------|------|:--:|
| 常规轮 | 每周例行 | 全量 | 标准报告 |
| 事件轮 | FOMC/CPI/地缘重大 | 全量 | 标准 + 事件冲击 |

账户数据 (ttfund) 不纳入轮次——用户问调仓时单独采集。

## Hard Constraints

- 报告阶段不得调用数据源；所有值取自已完成的 snapshot
- 不得修改 snapshot
- 规则文件禁止写回运行结果
- 叙事必须可追溯到 snapshot 或 provenance 中的具体行
- **禁止 M2/M3/T1/T2 等不可测或伪精确计数条件**——只使用有明确 snapshot 数据的可测条件
- **允许"数据不足以判断"作为有效结论**
