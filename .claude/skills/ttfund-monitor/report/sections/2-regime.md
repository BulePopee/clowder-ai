# Section 2: Market Wind Diagnosis

## Purpose

数据驱动的市场风向判断。先列数据方向，再从资产联动反推主导驱动力。不做 regime 选择题。

## Protocol

1. 从 snapshot 提取关键资产方向数据
2. 填资产方向表 → 看"什么在动"
3. 从资产联动判断主导驱动力 → 看"为什么动"
4. 列出证据链（支持判断的数据 + 与判断矛盾的数据）
5. 标注不确定项
6. 末尾一句话辅助标签（可选）
