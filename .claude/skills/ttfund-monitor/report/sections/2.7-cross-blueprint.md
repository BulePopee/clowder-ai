# Section 2.7: Cross-Blueprint Consistency (P3.2-B)

## Purpose

展示跨 blueprint 一致性检测结果。从 `feedback.json` 读取 cross_refs，不引入新数据源。这是"观测层"——只展示跨资产信号，不做操作建议。

## Input

- `{runtimeRoot}/runs/{runId}/feedback.json`（P3.2-A 产物）

## Protocol

1. 读 `feedback.json`
2. 如果 `cross_refs` 为空 → 输出"本轮无跨资产一致性信号"
3. 如果有 cross_refs → 渲染全部 cross_refs 为表格
4. 给出一句话一致性评估

## Template

```markdown
### 2.7 跨资产一致性

> P3.2 跨 blueprint 反馈检测。来源: feedback.json

{cross_refs 为空时: 本轮无跨资产一致性信号。各 blueprint 之间未检测到需要交叉调整的矛盾。}

{cross_refs 非空时:}

| # | 来源 | 信号 | 目标 | 调整 |
|---|------|------|------|------|
{每条 cross_ref: | {id} | {from_blueprint} → {to_blueprint} | {signal} | {adjustment.type} {adjustment.delta}{adjustment.unit}: {adjustment.reason} |}

**一致性评估**: {一致 / 轻微张力 / 矛盾} — {一句话总结跨 blueprint 信号的整体含义}

{一致性评估指引:
- 一致: 所有 cross_refs 互相加强，不冲突
- 轻微张力: 有 1-2 条 cross_refs 指向不同方向，但整体可调和
- 矛盾: 多条 cross_refs 指向相反方向，需关注}
```

## Hard Constraints

- 不引入新数据源，所有值取 feedback.json
- 不输出操作建议（操作建议在 Ch6）
- cross_refs 为空时只输出一句话，不加表格
- 一致性评估不能超过 2 句话
