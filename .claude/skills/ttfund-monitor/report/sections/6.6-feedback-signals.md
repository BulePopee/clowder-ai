# Section 6.6: Feedback Signals Reference (P3.2-B)

## Purpose

从 `feedback.json` 中筛选对决策门禁有直接影响的反馈信号，单独列出作为 Ch6 决策参考。只展示 `add_condition_to_act` 和 `add_invalidation_condition` 类型的 cross_refs，不重复 Ch2.7 的全量内容。

## Input

- `{runtimeRoot}/runs/{runId}/feedback.json`（P3.2-A 产物）

## Protocol

1. 读 `feedback.json`
2. 筛选 `cross_refs` 中 `adjustment.type` 为 `add_condition_to_act` 或 `add_invalidation_condition` 的条目
3. 无匹配条目 → 输出"本轮反馈无决策门禁相关信号"
4. `action_advice_allowed === false` → 追加免责声明"反馈信号参考不可转化为操作建议"
5. 每条信号标注参考权重（低/中/高）

## Template

```markdown
### 6.6 反馈信号参考

> P3.2 跨 blueprint 反馈中与决策门禁相关的信号。来源: feedback.json

{无决策相关信号时: 本轮反馈无决策门禁相关信号。}

{有信号时:}

| # | 信号 | 来源 | 参考权重 | 说明 |
|---|------|------|:--:|------|
{每条信号: | {id} | {from_blueprint} → {to_blueprint} | {低/中/高} | {signal 或 adjustment.reason} |}

{action_advice_allowed === false 时追加: > 当前 action_advice_allowed=false，以上反馈信号仅供观测参考，不可转化为操作建议。}
```

## 参考权重判定

- 高: `add_invalidation_condition` 类型（指向当前判断可能失效）
- 中: `add_condition_to_act` 类型 + 阈值已 crossing（非 approaching）
- 低: `add_condition_to_act` 类型 + 阈值仅 approaching

## Hard Constraints

- 不重复 Ch2.7 内容（只列 decision-relevant 的 cross_refs）
- action_advice_allowed=false 时必须有免责声明，否则报 validator 错误
- 不输出操作建议
- 不引入新数据源
