## 价格区间方法说明

### 计算公式
```
上轨 = close + 2 × ATR5
下轨 = close - 2 × ATR5
```

### 置信度解释
- **2×ATR ≈ 95% 置信区间**: 基于经验类比（对应正态分布 2σ），实际市场因厚尾效应，真实覆盖率可能略低于 95%
- **适用场景**: 3-5 日短期价格波动预测，适合日内/隔夜/短线交易的止损止盈参考

### 数据来源
- `close`: 当前收盘价（来自 `candidates.json` 的 `trend.close`）
- `ATR5`: 5 日平均真实波动幅度（来自 `candidates.json` 的 `indicators.atr5`）

### 使用注意
1. ⚠️ **非严格统计**: ATR 通道的"95%"是经验类比，不是统计学严格定义的置信区间
2. ⚠️ **突发事件失效**: 地缘政治、政策变化等黑天鹅事件会使历史 ATR 失效
3. ⚠️ **品种差异**: 不同品种的 ATR 倍数需优化（当前统一用 2×，实际可根据品种特性调整为 1.5-3）
4. ✅ **交叉验证**: 建议与 MA20/MA60 支撑阻力位、持仓量变化、成交量放大等指标联合使用
