# Section 6: Decision Conclusion

## Purpose

基于第 2 章市场风向判断，给出操作倾向。每条建议必须有数据证据链。讨论的是"什么操作在当前数据下合理"，不是"系统发出了什么信号"。

## Template

```markdown
## 6. 操作建议

**建议等级**：{正常建议/数据不足/仅观察}（关键指标 {n}/{total}，缺口 {x}）

### 6.1 场景树

| 场景 | 优先级 | 触发条件 | 组合影响 | 操作倾向 |
|---|---:|---|---|---|
| 基准 | {高/中/低} | {当前趋势延续} | {对当前持仓的影响} | {维持/观望} |
| 恶化 | {高/中/低} | {风险触发条件} | {下行路径} | {防御/减仓讨论} |
| 修复 | {高/中/低} | {修复触发条件} | {修复路径} | {恢复/加仓讨论} |

优先级为主观权重，非精确概率。

### 6.2 操作建议

{数据变化} → {风险含义} → {操作倾向}。引用 `decision-engine.md` §Condition → Action Traceability。

**建议 1**：{动作描述}。证据：{具体数据点}。等级：{执行级/建议级/讨论级}

**建议 2**：...

### 6.3 不操作的理由

{列出看起来"应该操作"但实际上条件不满足的情况，说明为什么不触发}

### 6.4 判断失效条件

本轮主导判断：{第 2 章的主导驱动力}

若出现以下情况，当前判断需要重评：

1. {与主导驱动力矛盾的数据变化}
2. {指向另一种驱动的数据变化}
3. {极端事件触发}

### 6.5 复检时点

- 常规：{下次例行监测时间}
- 事件触发：{FOMC/CPI/地缘 即时加轮条件}
```

## Hard Constraints

- 每个操作建议必须引用数据证据（格式：`{数据变化} → {风险含义} → {操作倾向}`）
- 关键指标缺口时：禁止"建议加仓/减仓/买入/卖出"，只允许"维持观望"或"数据不足"
- 动作等级必须与 `decision-engine.md` §动作等级 一致
- 建议等级 ≤ 动作等级
- 讨论级建议必须标注"等待下一轮确认"
- 执行级建议必须关键指标全齐 + 置信度 ≥ 中高

## Report Mode Degradation

关键指标缺口时：
- 禁止写"建议加仓/减仓/买入/卖出"
- 只允许"维持观望"或"数据不足，无法判断"
- 标注"此建议基于非全量数据，置信度 {level}"
